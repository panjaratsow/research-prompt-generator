# Research Prompt Generator

A static web application for generating structured AI prompts across an academic research workflow.

## What It Includes

- Step 1: Finding research ideas and research gaps
- Step 2: Literature review
- Step 3: Evidence synthesis
- Step 4: Research gap prioritization
- Step 5: Hypothesis generation
- Step 6: Research methodology
- Step 7: Research proposal writing
- Citation, language, role, field, setting, target-output, and evidence fields
- Guardrails against fabricated citations, invented data, and unverified claims
- Copy and download prompt actions

## Privacy

This is a static HTML/CSS/JavaScript app. It does not use a server, database, analytics, cookies, or external API calls. User input stays in the browser unless the user copies or downloads it.

## Local Use

Open `index.html` in a browser.

## Publish With GitHub Pages

1. Create a public GitHub repository.
2. Upload these files to the repository root:
   - `index.html`
   - `styles.css`
   - `app.js`
   - `favicon.svg`
   - `site.webmanifest`
   - `.nojekyll`
   - `README.md`
   - `LICENSE`
3. In GitHub, open `Settings` > `Pages`.
4. Under `Build and deployment`, choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Save. GitHub will provide a public URL after deployment.

## Publish With Netlify

Drag and drop the project folder into Netlify Drop, or connect the repository. No build command is needed.

## Publish With Vercel

Import the repository as a static site. No build command is needed.
